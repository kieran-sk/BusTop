# 🚍 BusTop — Αστικές Συγκοινωνίες Αθηνών (ΟΑΣΑ Live)

Σύγχρονο Progressive Web App (PWA) για ζωντανές αφίξεις λεωφορείων, τηλεματική, δρομολόγια, χάρτη στάσεων και έξυπνες ειδοποιήσεις για την Αθήνα.

## ✨ Δυνατότητες
- **Πίνακας Αφίξεων Αεροδρομίου:** Ζωντανές αφίξεις με εφέ split-flap και υπολογισμό χρόνου περπατήματος.
- **Όλες οι Στάσεις Περιοχής:** Προβολή όλων των κοντινών στάσεων με γραμμές και αποστάσεις.
- **Ζωντανές Ειδοποιήσεις & Αντίστροφη Μέτρηση:** Live notifications στην οθόνη κλειδώματος με συνεχή ενημέρωση λεπτών.
- **Δυνατή Σειρήνα Συναγερμού:** Ειδοποίηση με σειρήνα και δόνηση όταν πλησιάζει το λεωφορείο.
- **Χάρτης OpenStreetMap / Leaflet:** Προβολή στάσεων, διερχόμενων γραμμών και στίγματος οχημάτων σε πραγματικό χρόνο.
- **Cloudflare Edge Proxy:** Ταχύτατο routing και caching μέσω Cloudflare Pages & Workers στο datacenter της Αθήνας.
